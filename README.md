## ChatCat
With this app, you can cannect to a server and call your friends! To set up on your wifi, you would need a server that runs Windows Server 2012 or later and is wired to the internet. Then you have to download the server.exe file form the server branch. Run it and go to CMD. Run ipconfig and look for the IPv4 adress. Wright this down. Open the app and Wright what you just wrote. Now you can call or text anyone in your house!
